# UGUI Playable

Timeline tracks, clips and UI Toolkit editor tooling for animating uGUI in Unity.

> Status: early development. No tracks are available yet.

## Requirements

- Unity 6000.3 or newer
- Timeline 1.8.13+, uGUI 2.0.0+

## Installation

Open **Window > Package Manager**, choose **+ > Install package from git URL…** and enter:

```text
https://github.com/<owner>/<repo>.git?path=Packages/com.apexiongame.ugui-playable
```

Append `#v<version>` to pin a release.
