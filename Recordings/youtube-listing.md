## Title

UGUI Playable — animate Unity UI with Timeline, no tween code (Showcase)

## Description

A 42-second trailer built with UGUI Playable, an open-source (MIT) Unity package that adds Timeline tracks for uGUI.
Everything you see is one Timeline asset. No tween code and no Animator.

UGUI Playable gives you 15 Timeline tracks for Unity UI: Rect Transform, Graphic, Image, Raw Image, Canvas Group,
Shadow/Outline, Layout Element, Layout Group, Grid Layout Group, Slider, Scrollbar, Scroll Rect, Toggle, TMP Text and
TMP Characters. Clips blend, scrub and preview in Edit Mode like any Timeline track.

In this video:
- per-character TextMeshPro effects: bounce, wave, shake, random-order assembly
- scramble reveal, word-by-word typewriter with punctuation pauses, and rich-text-safe text tweens
- a number counter with thousands separators
- colour, fill, UV scroll, layout spacing, grid cell size, slider, scroll rect and toggle animation
- shadow, shortest-path rotation, punch and shake effects
- parametric Back and Elastic eases
